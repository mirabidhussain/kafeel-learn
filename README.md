# Kafeel's Learn & Practice

A simple learning web app for a Grade 1 (CBSE) student: short illustrated lessons, read aloud, followed by 5 practice questions per topic.

**Topics**
- **Maths:** Counting, Add & Subtract, More & Less, Patterns, Word Problems, Tens & Ones, Money (₹), Shapes, Telling Time (read and set the clock)
- **Logic & Coding:** Logical Thinking, Coding: Directions (Scratch-style blocks), Coding: Loops & Order
- **Science:** Push & Pull, Living & Non-living, Animal Homes, Float & Sink, Our Senses, Solid/Liquid/Gas, Solar System

Two levels: Little (3–5) and Big (6–9).

## Run it
It is a single file, `index.html`, with no build step. Open it in any browser, or visit the GitHub Pages site for this repository.
