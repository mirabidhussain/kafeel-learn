# My Expenses

A simple, fully offline expenses app in ₹: add, edit and delete expenses, 10 categories, payment method (Cash/UPI/Card/Bank), monthly budget, category summary, 6-month chart, search, and copy-to-clipboard backup/restore and CSV.

- `index.html`: the whole app (also works in any browser)
- `android/`: WebView wrapper; GitHub Actions builds `MyExpenses.apk` into the **latest** release on every push.
